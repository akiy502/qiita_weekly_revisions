## Purpose

保存済みの版の更新日を一覧表示し、閲覧者が選んだ日の版がプレビューされた状態の Qiita revisions ページへ直接遷移できるようにする。

## ADDED Requirements

### Requirement: 更新日の一覧表示（ユビキタス）
閲覧ページは、データファイルに含まれる全版の更新日を日本標準時（JST）の日付と曜日で表示し、年・月ごとにまとめて新しい順に並べること。

#### Scenario: UTC の更新日時が JST の日付で表示される
- **GIVEN** データファイルに更新日時 `2026-10-10T20:12:41Z` の版が含まれる
- **WHEN** 閲覧者が閲覧ページを開いたとき
- **THEN** その版は「2026 年 10 月」のまとまりの中に「10/11(日)」として表示されること

#### Scenario: 新しい順に並ぶ
- **GIVEN** データファイルに JST で 2026-10-08 と 2026-10-11 の版が含まれる
- **WHEN** 閲覧者が閲覧ページを開いたとき
- **THEN** 「10/11」が「10/08」より前に表示されること

### Requirement: 選んだ版への遷移（イベント駆動）
閲覧者が一覧の日付を選択したとき、閲覧ページは `https://qiita.com/Qiita/items/b5c1550c969776b65b9b/revisions?id=<版 ID を URL エンコードした文字列>` を新しいタブで開くこと。

#### Scenario: 版 ID が URL エンコードされて開かれる
- **GIVEN** 一覧に版 ID `IkFydGljbGVTbmFwc2hvdC0xNjYyNTUyOSI=--5d2b5b22` の版が表示されている
- **WHEN** 閲覧者がその日付を選択したとき
- **THEN** 新しいタブで `https://qiita.com/Qiita/items/b5c1550c969776b65b9b/revisions?id=IkFydGljbGVTbmFwc2hvdC0xNjYyNTUyOSI%3D--5d2b5b22` が開くこと

### Requirement: 版が 0 件の場合の表示（望ましくない事象）
データファイルに版が 1 件も含まれない場合、閲覧ページは「表示できる版がありません」というメッセージを表示すること。

#### Scenario: データが空
- **GIVEN** データファイルの版一覧が空である
- **WHEN** 閲覧者が閲覧ページを開いたとき
- **THEN** 「表示できる版がありません」と表示されること

### Requirement: スマートフォン幅での表示（ユビキタス）
閲覧ページは、表示領域の幅が 375px のとき、横スクロールを発生させずに一覧を表示すること。

#### Scenario: iPhone 幅で横スクロールしない
- **GIVEN** データファイルに 100 版が含まれる
- **WHEN** 閲覧者が幅 375px の画面で閲覧ページを開いたとき
- **THEN** ページの表示幅が 375px を超えないこと
