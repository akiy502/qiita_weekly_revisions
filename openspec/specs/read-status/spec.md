# read-status Specification

## Purpose
閲覧者がどの版を見たかをブラウザ内に記録し、未読の版だけを絞り込めるようにする。端末間で既読を移せるよう、エクスポートとインポートも提供する。

## Requirements

### Requirement: 既読の記録（イベント駆動）
閲覧者が一覧の日付を選択したとき、閲覧ページはその版を既読として記録し、その日付の表示を既読の見た目に切り替えること。

#### Scenario: 選んだ日付が既読になる
- **GIVEN** 版 A が未読として表示されている
- **WHEN** 閲覧者が版 A の日付を選択したとき
- **THEN** 版 A が既読の見た目で表示されること

### Requirement: 既読と未読の見分け（ユビキタス）
閲覧ページは、既読の版と未読の版を、色以外の手がかり（記号または文言）でも区別できるように表示すること。

#### Scenario: 記号で区別できる
- **GIVEN** 版 A が既読、版 B が未読である
- **WHEN** 閲覧者が閲覧ページを開いたとき
- **THEN** 版 A と版 B に異なる記号または文言が付いて表示されること

### Requirement: 既読の保持（ユビキタス）
閲覧ページは、同じブラウザでページを再読み込みまたは開き直したときに、記録済みの既読状態を復元すること。

#### Scenario: 再読み込み後も既読のまま
- **GIVEN** 版 A を既読にした
- **WHEN** 閲覧者が同じブラウザで閲覧ページを再読み込みしたとき
- **THEN** 版 A が既読の見た目で表示されること

### Requirement: 既読の版 ID 変化への耐性（ユビキタス）
閲覧ページは、版 ID の署名部分（`--` 以降）だけが変わった版を、変わる前と同じ版として既読状態を引き継ぐこと。

#### Scenario: 署名だけ変わった版
- **GIVEN** 版 ID `IkFydGljbGVTbmFwc2hvdC0xNjYyNTUyOSI=--aaaa` の版を既読にした
- **AND** データファイル更新後、同じ版の版 ID が `IkFydGljbGVTbmFwc2hvdC0xNjYyNTUyOSI=--bbbb` になった
- **WHEN** 閲覧者が閲覧ページを開いたとき
- **THEN** その版が既読の見た目で表示されること

### Requirement: 未読に戻す（イベント駆動）
閲覧者が既読の版に対して「未読に戻す」操作をしたとき、閲覧ページはその版の既読記録を削除し、未読の見た目で表示すること。

#### Scenario: 既読を取り消す
- **GIVEN** 版 A が既読である
- **WHEN** 閲覧者が版 A に「未読に戻す」操作をしたとき
- **THEN** 版 A が未読の見た目で表示されること
- **AND** 再読み込み後も版 A が未読の見た目で表示されること

### Requirement: 未読のみフィルタ（オプション）
「未読のみ」フィルタが有効な場合、閲覧ページは既読の版を一覧に表示しないこと。

#### Scenario: 既読が隠れる
- **GIVEN** 版 A が既読、版 B が未読である
- **WHEN** 閲覧者が「未読のみ」フィルタを有効にしたとき
- **THEN** 一覧に版 B が表示され、版 A が表示されないこと

#### Scenario: フィルタを解除すると全件に戻る
- **GIVEN** 「未読のみ」フィルタが有効で、版 A（既読）が非表示である
- **WHEN** 閲覧者が「未読のみ」フィルタを無効にしたとき
- **THEN** 一覧に版 A が表示されること

### Requirement: フィルタ状態の保持（ユビキタス）
閲覧ページは、同じブラウザでページを再読み込みしたときに「未読のみ」フィルタの有効・無効の状態を復元すること。

#### Scenario: 再読み込み後もフィルタが有効
- **GIVEN** 「未読のみ」フィルタを有効にした
- **WHEN** 閲覧者が閲覧ページを再読み込みしたとき
- **THEN** 「未読のみ」フィルタが有効な状態で表示されること

### Requirement: ファイルへのエクスポート（イベント駆動）
閲覧者が「ファイルにエクスポート」を実行したとき、閲覧ページは全既読記録を含む JSON ファイルをダウンロードさせること。

#### Scenario: 既読が JSON ファイルとして保存される
- **GIVEN** 3 つの版が既読である
- **WHEN** 閲覧者が「ファイルにエクスポート」を実行したとき
- **THEN** 3 つの版の既読記録を含む `.json` ファイルがダウンロードされること

### Requirement: テキストへのエクスポート（イベント駆動）
閲覧者が「テキストでコピー」を実行したとき、閲覧ページはファイルへのエクスポートと同じ内容の JSON 文字列をクリップボードにコピーすること。

#### Scenario: 既読がクリップボードにコピーされる
- **GIVEN** 3 つの版が既読である
- **WHEN** 閲覧者が「テキストでコピー」を実行したとき
- **THEN** クリップボードに 3 つの版の既読記録を含む JSON 文字列が入ること

### Requirement: マージでのインポート（イベント駆動）
閲覧者がファイル選択またはテキスト貼り付けで既読データを読み込み、マージを選んだとき、閲覧ページは現在の既読記録と読み込んだ既読記録の和集合を既読記録として保存すること。

#### Scenario: 和集合になる
- **GIVEN** 版 A と版 B が既読である
- **AND** 読み込むデータには版 B と版 C の既読記録が含まれる
- **WHEN** 閲覧者がマージでインポートしたとき
- **THEN** 版 A、版 B、版 C が既読の見た目で表示されること

### Requirement: インポート方法の既定値（ユビキタス）
閲覧ページは、インポート方法の選択肢の初期値をマージにすること。

#### Scenario: 初期状態はマージ
- **WHEN** 閲覧者がインポートの操作画面を開いたとき
- **THEN** インポート方法としてマージが選択された状態で表示されること

### Requirement: 上書きでのインポート（複合）
閲覧者が既読データを読み込んで上書きを選び、確認ダイアログで承諾したとき、閲覧ページは現在の既読記録を読み込んだ既読記録で置き換えること。

#### Scenario: 置き換わる
- **GIVEN** 版 A と版 B が既読である
- **AND** 読み込むデータには版 C の既読記録だけが含まれる
- **WHEN** 閲覧者が上書きでインポートし、確認ダイアログで承諾したとき
- **THEN** 版 C だけが既読の見た目で表示されること

#### Scenario: 確認ダイアログで取り消す
- **GIVEN** 版 A と版 B が既読である
- **WHEN** 閲覧者が上書きでインポートし、確認ダイアログで取り消したとき
- **THEN** 版 A と版 B が既読のままであること

### Requirement: 不正なインポートデータの拒否（望ましくない事象）
読み込んだデータが既読データの形式として解釈できない場合、閲覧ページはエラーメッセージを表示し、既読記録を変更しないこと。

#### Scenario: JSON ではないテキストを貼り付けた
- **GIVEN** 版 A が既読である
- **WHEN** 閲覧者が「hello」という文字列を貼り付けてインポートしたとき
- **THEN** 読み込めなかったことを示すエラーメッセージが表示されること
- **AND** 版 A が既読のままであること

### Requirement: ブラウザストレージが使えない場合の動作（望ましくない事象）
ブラウザのストレージに読み書きできない場合、閲覧ページは一覧表示と版への遷移を引き続き提供し、既読を保存できないことを示すメッセージを表示すること。

#### Scenario: ストレージが無効
- **GIVEN** ブラウザのストレージへの書き込みが拒否される
- **WHEN** 閲覧者が閲覧ページを開いたとき
- **THEN** 更新日の一覧が表示されること
- **AND** 既読を保存できないことを示すメッセージが表示されること
