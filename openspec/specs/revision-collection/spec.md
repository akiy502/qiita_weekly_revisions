# revision-collection Specification

## Purpose
Qiita「週間トレンド記事一覧」の revisions ページから版の一覧（更新日時と版 ID）を取得し、閲覧ページが読み込めるデータファイルとして差分で蓄積する。

## Requirements

### Requirement: 版一覧の取得（イベント駆動）
取得スクリプトが実行されたとき、取得スクリプトは `https://qiita.com/Qiita/items/b5c1550c969776b65b9b/revisions?page=N` を `N=1` から順に取得し、各ページに含まれる全版の更新日時と版 ID をデータファイルに保存すること。

#### Scenario: 初回取得で全版が保存される
- **GIVEN** データファイルが存在しない
- **AND** revisions ページが 3 ページあり、合計 25 版を含む
- **WHEN** 取得スクリプトを実行したとき
- **THEN** データファイルに 25 版の更新日時と版 ID が保存されること

### Requirement: 最終ページでの停止（イベント駆動）
取得したページが最終ページであると示されたとき、取得スクリプトは次のページを取得しないこと。

#### Scenario: 最終ページの後は取得しない
- **GIVEN** revisions ページが 3 ページある
- **WHEN** 取得スクリプトを実行したとき
- **THEN** 取得スクリプトが送るページ取得リクエストは `page=1` から `page=3` までの 3 回であること

### Requirement: 差分取得（イベント駆動）
データファイルに既に存在する版 ID を含むページを取得したとき、取得スクリプトはそのページで新規の版だけを追加し、以降のページを取得しないこと。

#### Scenario: 新しい版だけが追加される
- **GIVEN** データファイルに 25 版が保存されている
- **AND** その後 2 版が追加され、revisions ページの 1 ページ目の先頭 2 件が未保存の版である
- **WHEN** 取得スクリプトを実行したとき
- **THEN** データファイルの版数が 27 になること
- **AND** 取得スクリプトが送るページ取得リクエストは `page=1` の 1 回だけであること

### Requirement: 差分がない場合の無変更（イベント駆動）
取得した版がすべてデータファイルに存在していたとき、取得スクリプトはデータファイルの内容をバイト単位で変更しないこと。

#### Scenario: 新しい版がないときはファイルが変わらない
- **GIVEN** データファイルに revisions ページ上の全版が保存されている
- **WHEN** 取得スクリプトを実行したとき
- **THEN** データファイルの内容が実行前と同一であること

### Requirement: データファイルの並び順と一意性（ユビキタス）
取得スクリプトは、データファイル内の版を更新日時の降順に並べ、同じ版 ID を 2 回以上含めないこと。

#### Scenario: 降順かつ重複なしで保存される
- **GIVEN** 1 ページ目と 2 ページ目の境界で同じ版が両方のページに現れる
- **WHEN** 取得スクリプトを実行したとき
- **THEN** データファイル内でその版は 1 回だけ現れること
- **AND** データファイルの先頭の版が最も新しい更新日時を持つこと

### Requirement: リクエスト間隔（ユビキタス）
取得スクリプトは、qiita.com へ連続して送るリクエストの開始時刻の間隔を 1 秒以上空けること。

#### Scenario: 連続リクエストの間隔
- **GIVEN** 取得対象が 3 ページある
- **WHEN** 取得スクリプトを実行したとき
- **THEN** 隣り合うリクエストの開始時刻の差がすべて 1 秒以上であること

### Requirement: 版一覧を読み取れない場合の中断（望ましくない事象）
取得したページから版一覧データを読み取れない場合、取得スクリプトは 0 以外の終了コードで終了し、データファイルを変更しないこと。

#### Scenario: ページ構造が変わっていた
- **GIVEN** データファイルに 25 版が保存されている
- **AND** revisions ページに版一覧データが埋め込まれていない
- **WHEN** 取得スクリプトを実行したとき
- **THEN** 取得スクリプトの終了コードが 0 以外であること
- **AND** データファイルの内容が実行前と同一であること

### Requirement: 通信失敗時の中断（望ましくない事象）
ページ取得の HTTP ステータスが 200 以外であるか通信に失敗した場合、取得スクリプトは 0 以外の終了コードで終了し、データファイルを変更しないこと。

#### Scenario: サーバーエラーが返った
- **GIVEN** データファイルに 25 版が保存されている
- **AND** revisions ページが HTTP 503 を返す
- **WHEN** 取得スクリプトを実行したとき
- **THEN** 取得スクリプトの終了コードが 0 以外であること
- **AND** データファイルの内容が実行前と同一であること
